# Third-party licences

Atonacht bundles these fonts so it works with no network:

| Font | Licence | Text |
| --- | --- | --- |
| Inter | SIL Open Font License 1.1 | `Inter-OFL.txt` |
| Fraunces | SIL Open Font License 1.1 | `Fraunces-OFL.txt` |

The libraries (React, CodeMirror, Tauri and its plugins, fflate) are MIT or Apache-2.0; the app's About panel lists
them. Their full texts live in `node_modules` for each package, and `THIRD-PARTY.md` names the versions that shipped.
